# capstone-project1
REAL TIME ACCENT TRANSLATION
This is a AI driven project majorly uses free resources from google.
It uses GTTs,SR,pyaudio, translator etc.
The translator can translate 3 languages and 3 accents they are Telugu,Hindi,Kannada and Indian english,Us-english,UK-english.
This Project is devleoped for Video conferences hence ,the interface for the audio "VB-cable" sofware is used.
there are 3 files named as mainly
1."accenttranslationapp/python_code_for_uni directional Translation": whcih can be used for video conferneces in 3 languages and 3 accents. The voices from the opposite persons (who ever speaks in the video confernece meeting) thier voice is translated according to the preference set by the user (which are 3 languages and 3 accents in the project) 
2."accenttranslationapp/Full_python_code Bi-directional translation": whcih can be used for video conferneces in 3 languages and 3 accents. The voices from the opposite persons (who ever speaks in the video confernece meeting) thier voice is translated according to the preference set by the user (which are 3 languages and 3 accents in the project) and the user voice is also translated and sent in the meeting via VB-cable with same 3 languages and 3 accents which is Bi directional.
3."accenttranslationapp/Full_python_code Bi directional translation2": whcih can be used for video conferneces in 3 languages and 3 accents. The voices from the opposite persons (who ever speaks in the video confernece meeting) thier voice is translated according to the preference set by the user (which are 3 languages and 3 accents in the project) and the user voice is also translated and sent in the meeting via VB-cable with same 3 languages and 3 accents which is Bi directional. Same as the number 2 but in another method.
Then there are test codes for audio : "accenttranslationapp/Testing VB cable for audio" ,"accenttranslationapp/Testing VB cable for audio 2"
Backend.py and index.html files are early version of app with different methods which is partial to the main files.
